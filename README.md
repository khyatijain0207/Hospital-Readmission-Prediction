# Hospital Readmission Prediction

## Overview

This project predicts whether a patient will be readmitted to the hospital within 30 days using **Logistic Regression with L2 Regularization**.

## Techniques Used

- Logistic Regression
- L2 Regularization
- Data Preprocessing
- One-Hot Encoding
- Standard Scaling
- ROC-AUC Evaluation
- Confusion Matrix
- Clinical Error Analysis

## Dataset

The project uses the **Diabetic Patients' Re-admission Prediction** dataset.

The dataset is not included in this repository because of its size.
